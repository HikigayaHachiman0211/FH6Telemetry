# 玩家运行指南

**简体中文** · [English](en/user-guide.md) · [日本語](ja/user-guide.md) · [한국어](ko/user-guide.md)

## 第一次运行

1. 把 `FH6Telemetry.exe` 放在可以写入的目录，双击打开。HUD 随窗口显示，可在左上角开关。 [下载 Windows x64 版](https://github.com/HikigayaHachiman0211/FH6Telemetry/releases/latest/download/FH6Telemetry.exe)
2. 在 FH6 的「设置 → HUD 和游戏性」开启 Data Out。同一台电脑填 IP `127.0.0.1` 和端口 `20440`。端口改过时，在助手「模块设置」中同步。
3. 点助手的「开始接收」。回到游戏自由漫游，在「实时总览」确认车速、挡位、转速跟随游戏。停车时可以轻踩刹车，用踏板百分比判断是否在收包。 [Forza Data Out 说明](https://support.forza.net/hc/en-us/articles/51744149102611-Forza-Horizon-6-Data-Out-Documentation)

「HUD 设置」可以拖动位置，调节大小和不透明度，并逐项选择显示内容。透明度主要用于背景，文字可独立开启高对比度描边。修改后点「保存 HUD 设置」，下次启动会沿用。

## 自动换挡

先在 FH6 选择「手动」或「手动（带离合器）」。在助手的「自动换挡」页选择输出方式。确认自动换挡与驾驶辅助停用后，可在「虚拟手柄配置」运行「静止自检升挡」。

| 输出方式 | 适用情形 | 对照键位 |
| --- | --- | --- |
| 实体手柄兼容 · 键盘换挡 | 新配置的默认输出。实体手柄继续直接控制游戏，助手发键盘换挡。 | 默认 `E` 升挡、`Q` 降挡、左 `Shift` 离合、`W` 补油。与游戏当前键盘布局对齐。 |
| 单手柄转发 · 内置离合与补油 | 由助手转发实体 XInput 手柄，并用虚拟手柄发送组合输入。驾驶辅助的主动输出使用此路径。 | `B` 升挡、`X` 降挡、`L3` 离合、`RT` 油门、`LT` 刹车、左摇杆转向。 |

使用单手柄转发时，按「虚拟手柄配置」的步骤安装 ViGEmBus 和 HidHide，复制该页显示的运行程序路径到 HidHide 的允许列表，并选择要转发的实体手柄。成功连接后，从启动器或 Windows 的设备视图核对虚拟手柄，再回到游戏确认实体操作能转发。若 FH6 在转发前已经启动，可保持转发并正常重启游戏，让它重新识别手柄。 [详细部署与排错](fh6-telemetry-agent-setup.md#单手柄转发)

静止自检时，停车挂一挡。点「静止自检升挡」后在 15 秒内回到前台游戏，保持踩住刹车并松开其他踏板和手刹。游戏遥测确认二挡后再试正常自动换挡。助手默认用 `F9` 切换自动换挡，也可在「自动换挡」页点启用或停用。

自动离合默认开启。智能识别赛用变速箱会在合适的升挡时用遥测确认离合需求。显示「换挡未确认」时，先手动试同一组键，再检查游戏变速方式、焦点和输出链路。停用自动换挡会释放自动输入。需要停止虚拟手柄时，点「断开转发」。 [换挡策略和参数](performance-telemetry.md#九自动换挡)

## 驾驶辅助和急弯提示

1. 先完成单手柄转发。打开「驾驶辅助」，选一项功能或应用预设。
2. 主动输出仅用于离线练习。勾选「确认当前是离线练习」，再点「接通驾驶辅助」。影子或公平模式可用于先观察或记录。
3. 游戏内已开启 ABS 或牵引力控制时，在助手勾选对应的游戏辅助选项。默认 `Pause` 可停止辅助输出。可以在「快捷键」页检查或重绑。 [配置与验收](fh6-telemetry-agent-setup.md#分层验收)

在「测试功能 → 驾驶辅助」勾选「低速急弯保留转向」。车身稳定且弯外侧前轮还有抓地时，助手会优先保留持续的大舵角。遇到明显甩尾或外侧前轮失去抓地，原有保护可以接管。

「手动触发上限」可在 20–90 km/h 调节，默认 54 km/h。启用「按车辆表现自动学习上限」后，助手先用滑块值，收集当前车辆的稳定转弯样本。学到新上限后在出弯时更新，换车、性能指数变化或重启会重新积累样本。开关和手动数值会保存。HUD 默认在学到数值后显示「急弯上限」。如需关闭这一行，取消勾选「HUD 设置 → 急弯上限提醒」并保存。

## 行驶记录、回放与数据目录

在「数据诊断 → 行驶记录」开始录制，结束后保存。可在「快捷键」分别配置开始和停止录制。在「驾驶辅助 → 离线回放与历史路线」载入记录，对照实体输入、实录输出和当前设置重算的候选输出。早期记录缺少实体输入时仍可查看遥测。回放计算沿用记录中的车辆轨迹，不能替代实际试跑。

助手通常把本地设置和记录放在 `%APPDATA%\FH6Telemetry`。如果标准配置尚未建立，而启动器旁已有 `Data\telemetry-settings.json`，会使用该便携配置。可从「历史记录」打开实际目录。升级前先备份你使用的数据目录。请把公开分享的诊断资料限于复现所需片段。 [数据结构和导出](performance-telemetry.md#四数据存储与导出)

「关于」页可打开项目主页、与助手界面语言对应的使用指南和最新发布。「检查更新」会查询 GitHub。开启自动下载后，新版保存到更新文件夹，可在「关于」页打开。

## 常见问题

| 现象 | 先检查 |
| --- | --- |
| 一直等待遥测 | FH6 的 Data Out 是否开启，地址和端口是否一致，游戏是否在驾驶画面，同一端口是否被另一个实例占用。 |
| 收包增加但读数不变 | 查看「数据诊断」的解析失败计数和包长度，确认连接的是 FH6 Data Out。 |
| 手柄有双输入或游戏看不到手柄 | 查看「虚拟手柄配置」的实际运行路径与转发状态，核实同一只实体手柄的 HidHide 配对。 |
| 发了换挡但没有变挡 | 在游戏手动验证当前键位，再检查变速方式、刹车、游戏焦点和是否有重复映射。 |
| 学习提示一直在用手动上限 | 确认已接通驾驶辅助并勾选急弯实验与自动学习。做几次稳定转弯，让有效样本达到要求。 |
| 想恢复实体手柄直连 | 在助手中断开转发或正常退出。如仍隐蔽，按 HidHide 设置还原自己之前使用的设备可见性。 |

需要从源码构建、诊断驱动或做系统化验收时，参见 [Agent 部署指南](fh6-telemetry-agent-setup.md)。
