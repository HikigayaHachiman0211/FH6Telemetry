# 플레이어 가이드

[简体中文](../user-guide.md) · [English](../en/user-guide.md) · [日本語](../ja/user-guide.md) · **한국어**

## 처음 실행

1. 쓰기 가능한 폴더에 `FH6Telemetry.exe`를 두고 실행합니다. 창 위쪽 버튼으로 HUD를 표시하거나 숨길 수 있습니다. [Windows x64 다운로드](https://github.com/HikigayaHachiman0211/FH6Telemetry/releases/latest/download/FH6Telemetry.exe)
2. FH6의 **설정 → HUD 및 게임 플레이**에서 Data Out을 켭니다. 같은 PC에서는 IP를 `127.0.0.1`, 포트를 `20440`으로 설정하고 앱의 **모듈 설정**에서도 같은 값을 사용합니다. [Forza Data Out 공식 문서](https://support.forza.net/hc/en-us/articles/51744149102611-Forza-Horizon-6-Data-Out-Documentation)
3. **수신 시작**을 누르고 자유 주행으로 돌아갑니다. **실시간 요약**에서 속도, 기어, RPM이 바뀌는지 확인합니다. 정차 중에는 브레이크를 살짝 밟아 페달 값이 변하는지 확인할 수 있습니다.

**HUD 설정**에서 위치, 크기, 배경 투명도, 글자 외곽선과 표시 항목을 조절합니다. **HUD 설정 저장**을 누르면 다음 실행 때도 적용됩니다.

## 자동 변속

FH6에서 **수동** 또는 **클러치 수동**을 선택하고 앱의 **자동 변속**에서 출력 방식을 고릅니다.

| 출력 방식 | 용도 | 기본 입력 |
| --- | --- | --- |
| 실제 패드 호환 · 키보드 변속 | 실제 패드는 게임에 직접 연결한 채 키보드로 변속합니다. | `E` 업시프트, `Q` 다운시프트, 왼쪽 `Shift` 클러치, `W` 블립. 게임의 키보드 설정과 맞춥니다. |
| 단일 패드 릴레이 · 내장 클러치 및 블립 | XInput 패드를 가상 Xbox 패드로 전달합니다. 주행 보조의 능동 출력에 사용합니다. | `B` 업시프트, `X` 다운시프트, `L3` 클러치, `RT` 가속, `LT` 브레이크, 왼쪽 스틱 조향. |

릴레이를 쓰려면 **가상 패드 설정**의 안내에 따라 ViGEmBus와 HidHide를 설치합니다. HidHide에서 화면에 표시된 실행 파일을 허용하고 전달할 실제 패드를 선택합니다. 릴레이가 작동하는 상태에서 FH6를 시작하면 게임에서 가상 패드를 확인할 수 있습니다. [릴레이 구성 절차](agent-deployment.md#단일-패드-릴레이)

자동 변속과 주행 보조를 끄고 1단으로 정차합니다. **가상 패드 설정 → 정차 업시프트 점검**을 누른 뒤 15초 안에 게임으로 돌아가 브레이크만 밟고 유지합니다. 텔레메트리에서 2단을 확인한 뒤 **자동 변속** 또는 기본 단축키 `F9`로 켜서 주행합니다. 자동 변속을 끄면 자동 변속 입력이 해제됩니다. 가상 패드 전달을 중단할 때는 릴레이 연결을 따로 끊습니다.

자동 클러치는 기본으로 켜져 있습니다. 레이스 변속기 감지는 실제 변속 결과로 클러치 필요 여부를 확인합니다. 변속이 확인되지 않으면 같은 키를 게임에서 직접 눌러 보고 현재 프리셋, 변속 모드와 포커스를 확인합니다.

## 주행 보조와 급커브

1. 단일 패드 릴레이를 구성하고 **주행 보조**에서 기능을 선택하거나 프리셋을 적용합니다.
2. 능동 출력을 쓰려면 오프라인에서 **오프라인 연습 확인**을 선택하고 **주행 보조 활성화**를 누릅니다. 섀도 모드에서는 예상 출력을 볼 수 있고 공정 모드는 읽기 전용입니다.
3. 게임의 ABS 또는 트랙션 컨트롤을 사용하는 경우 앱에서도 해당 항목을 선택합니다. 기본 `Pause` 키로 보조 출력을 중지할 수 있습니다. 키 설정은 **단축키**에서 확인합니다.

**실험 기능 → 주행 보조**의 **저속 급커브에서 조향 입력 우선**을 켭니다. 차체가 안정적이고 바깥쪽 앞바퀴에 접지력이 남아 있으면 운전자가 계속 넣는 조향을 우선합니다. 접지력이 떨어지거나 뒤가 흐르면 기존 보호 기능이 개입할 수 있습니다.

**수동 작동 상한 속도**는 20~90 km/h이며 기본값은 54 km/h입니다. **코너링 성능으로 상한 속도 학습**은 수동값에서 시작해 안정적인 코너링 샘플이 쌓이면 코너를 빠져나온 뒤 상한을 갱신합니다. 차량이나 성능 지수가 바뀌거나 앱을 다시 시작하면 학습을 새로 진행합니다. 수동값과 모드 선택은 저장됩니다. 학습값 표시는 **HUD 설정 → 급커브 상한 알림**에서 켜거나 끄고 저장할 수 있습니다.

## 기록, 리플레이와 업데이트

**진단**에서 주행 기록을 시작하고 종료 후 저장합니다. **주행 보조 → 오프라인 리플레이 및 학습 경로**에서 실제 입력, 기록된 출력과 현재 설정으로 다시 계산한 출력을 비교할 수 있습니다. 리플레이는 이미 기록된 차량 움직임을 사용하므로 조향 느낌은 실주행에서도 확인합니다.

기본 설정 폴더는 `%APPDATA%\FH6Telemetry`입니다. 기본 설정 파일이 아직 없고 실행 파일 옆에 `Data\telemetry-settings.json`이 있으면 휴대용 설정을 사용할 수 있습니다. 기록 화면에서 현재 저장 위치를 열 수 있고 업데이트 전에는 설정과 기록을 백업합니다.

**정보**에서 프로젝트 홈, 현재 언어의 가이드, 최신 릴리스를 열 수 있습니다. **업데이트 확인**은 GitHub를 조회합니다. 자동 다운로드가 켜져 있으면 업데이트 폴더에 새 EXE를 저장합니다. [릴리스 다운로드](https://github.com/HikigayaHachiman0211/FH6Telemetry/releases/latest)

## 문제 해결

| 증상 | 먼저 확인할 항목 |
| --- | --- |
| 데이터 대기 상태가 지속됨 | Data Out, IP와 포트 일치, 게임 주행 화면, UDP 포트 점유 |
| 수신은 되지만 값이 비어 있음 | **진단**의 패킷 길이와 파싱 오류 |
| 패드가 중복되거나 인식되지 않음 | **가상 패드 설정**의 실행 경로, HidHide 대상 장치, 게임의 가상 패드 인식 |
| 변속 입력이 나갔지만 기어가 바뀌지 않음 | 같은 키로 수동 변속을 시험하고 클러치 모드, 기어, 게임 포커스를 확인 |
| 급커브 상한에 수동값만 표시됨 | 주행 보조, 실험 기능과 자동 학습이 켜져 있는지 확인하고 안정적으로 코너를 주행 |
| 실제 패드로 돌아가고 싶음 | 릴레이 연결을 끊거나 앱을 정상 종료하고, HidHide를 수동 설정했다면 이전 표시 상태로 복원 |
