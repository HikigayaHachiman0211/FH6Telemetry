# プレイヤー向けガイド

[简体中文](../user-guide.md) · [English](../en/user-guide.md) · **日本語** · [한국어](../ko/user-guide.md)

## 初回起動

1. 書き込み可能なフォルダーに `FH6Telemetry.exe` を置いて起動します。画面上部のボタンで HUD を表示または非表示にできます。 [Windows x64 版のダウンロード](https://github.com/HikigayaHachiman0211/FH6Telemetry/releases/latest/download/FH6Telemetry.exe)
2. FH6 の「設定 → HUD とゲームプレイ」で Data Out を有効にします。同じ PC では IP を `127.0.0.1`、ポートを `20440` に設定し、アプリの「モジュール設定」と一致させます。 [Forza Data Out の公式資料](https://support.forza.net/hc/en-us/articles/51744149102611-Forza-Horizon-6-Data-Out-Documentation)
3. 「受信開始」を押してフリーロームへ戻り、「リアルタイム」で車速やギアを確認します。停車中はブレーキを軽く踏み、ペダル入力が変化することを確認できます。

「HUD 設定」で位置、大きさ、背景の不透明度、文字の縁取り、表示項目を調整します。「HUD 設定を保存」を押すと次回も同じ設定を使えます。

## 自動シフト

FH6 で「マニュアル」または「クラッチ付きマニュアル」を選び、アプリの「自動シフト」で出力方式を選択します。

| 出力方式 | 用途 | 初期の割り当て |
| --- | --- | --- |
| 実機パッド併用 · キーボードシフト | 実機パッドはゲームに直接接続し、アプリからキーボードで変速します。 | `E` 上げ、`Q` 下げ、左 `Shift` クラッチ、`W` ブリッピング。ゲームのキーボード設定に合わせます。 |
| 単体コントローラー中継 · クラッチ＆ブリッピング内蔵 | XInput パッドを仮想 Xbox パッドに中継します。能動的な運転支援に使用します。 | `B` 上げ、`X` 下げ、`L3` クラッチ、`RT` アクセル、`LT` ブレーキ、左スティックで操舵。 |

中継を使う場合は「仮想パッド設定」の案内に従い、ViGEmBus と HidHide を用意します。HidHide で表示中の実行ファイルを許可し、対象の実機パッドを指定します。中継を開始した状態でゲームを開くと、仮想パッドを確認できます。 [コントローラー中継の詳細](agent-deployment.md#コントローラー中継)

自動シフトと運転支援を停止し、1 速で停車します。「仮想パッド設定 → 停車中のシフトアップを確認」を押して 15 秒以内にゲームへ戻り、ブレーキだけを踏み続けます。テレメトリで 2 速になることを確認してから「自動シフト」または既定の `F9` で有効にします。自動シフトを停止すると自動入力が解除されます。中継を停止する場合は中継を別に切断します。

自動クラッチは既定で有効です。レーシングトランスミッションの検出は、変速結果を使ってクラッチが必要か判定します。変速を確認できない場合は、まず同じ操作を手動で試し、ゲームの変速モードと割り当て、前面ウィンドウを確認してください。

## 運転支援と急カーブ

1. コントローラー中継を設定し、「運転支援」で機能を選ぶかプリセットを適用します。
2. 出力を有効にする場合は「オフライン練習を確認」にチェックを入れ、「運転支援を有効化」を押します。シャドーモードでは提案された出力を確認でき、公平モードは読み取り専用です。
3. ゲーム内の ABS やトラクションコントロールを使用している場合は、アプリ側で対応する項目を選びます。既定では `Pause` で支援出力を停止できます。割り当ては「ショートカット」で確認できます。

「試験機能 → 運転支援」で「低速の急カーブでステアリングを優先」を有効にします。車体が安定し、外側の前輪にグリップが残っている間は、継続した操舵入力を優先します。グリップを失った場合や車体後部が滑った場合は通常の保護が作動できます。

「手動の作動上限速度」は 20～90 km/h の範囲で、既定は 54 km/h です。「旋回性能から上限速度を学習」は手動値から始め、安定したサンプルがそろうと旋回終了後に上限を更新します。車両や性能指数が変わった場合と、アプリを再起動した場合に再学習します。手動値とモードは保存されます。「HUD 設定 → 急カーブ上限の表示」で通知を切り替え、設定を保存できます。

## 記録・再生・更新

「診断ログ」で走行記録を開始し、終了時に保存します。「運転支援 → オフライン再生と走行ライン」で実機入力、記録された出力、現在の設定で再計算した出力を比較できます。再生は記録時の車両挙動を使うため、運転感覚の確認は実走で行います。

設定の標準フォルダーは `%APPDATA%\FH6Telemetry` です。標準設定がまだ作成されていない場合は、起動ファイルの隣の `Data\telemetry-settings.json` を使用できます。履歴画面からデータフォルダーを開けます。更新前に設定と記録をバックアップしてください。

「アプリ情報」からプロジェクト、現在の言語のガイド、最新リリースを開けます。「更新を確認」で GitHub を確認し、自動ダウンロードが有効な場合は更新フォルダーに新しい EXE を保存します。 [最新リリース](https://github.com/HikigayaHachiman0211/FH6Telemetry/releases/latest)

## トラブル対応

| 症状 | 最初に確認すること |
| --- | --- |
| データ待ちが続く | Data Out、IP とポート、ゲームの走行画面、UDP ポートの使用状況 |
| 受信数が増えるが値が空欄 | 「診断ログ」のパケット長と解析エラー |
| パッドが重複する、または使えない | 「仮想パッド設定」の実行パス、HidHide の対象、ゲームから見える仮想パッド |
| 変速指示が出てもギアが変わらない | 手動で同じ割り当てを試し、クラッチの設定、現在のギア、ゲームのフォーカスを確認 |
| 急カーブ上限が手動値のまま | 運転支援、試験機能、自動学習が有効か確認し、安定した旋回を記録 |
| 実機パッドへ戻す | 中継を切断するか通常終了し、手動で HidHide を設定した場合は以前の表示状態に戻す |
